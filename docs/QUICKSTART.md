# 第一次使用研究工作台

安装完成后，可以直接浏览中文工作台。运行研究时才需要配置推理模型和可访问的市场数据源。

## 1. 从这份源码启动

从本仓库的 **Code → Download ZIP** 下载并解压，或使用 Git 克隆。在含有 `pyproject.toml` 的目录打开终端。准备 Python 3.11 或更高版本，以下命令在独立环境中安装当前目录的项目。

**macOS / Linux**

```sh
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
tradingagents-web --open
```

**Windows PowerShell**（以 Python 3.12 为例）

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\tradingagents-web.exe --open
```

浏览器应显示「工作台总览」。第一次打开时，任务和报告数量为零。启动期间请保持终端打开。若浏览器没有自动打开，手动访问 [本机工作台](http://127.0.0.1:8765)。用 `Ctrl+C` 可停止服务。

## 2. 配置模型

1. 在「系统设置 → 模型服务」选择你有访问权限的服务商，为「快速模型」和「深度模型」分别选择账号可用的模型。前者用于分析和辩论，后者用于研究主管和组合经理的决策。
2. 使用云端 API 时，在「凭证管理」填写对应服务的密钥，例如 OpenAI 对应 `OPENAI_API_KEY`。使用 Ollama 时，先启动本机服务，在工作台填写已下载模型的名称。
3. 如需中文报告，在「运行策略」把「报告输出语言」改为 `Chinese`。保存更改，新提交的任务会读取这组设置。

启动目录的 `.env` 也可提供凭证，可用仓库中的 [.env.example](../.env.example) 查看变量名。通过网页保存的密钥会随设置写入本机的 `~/.tradingagents/web/settings.json`。提交问题或分享截图时，请隐去密钥和持仓。

## 3. 跑一份报告

1. 进入「标的分析」，输入示例代码 `AAPL`，选择一个已收盘的交易日。第一次可以只勾选「技术分析」，持仓留空。
2. 点击「开始分析」。任务页会显示研究阶段、分析师报告和辩论发言。使用云端模型时，这一步会按服务商规则消耗额度。默认股票行情来自 yfinance，需要能访问相应的数据服务。
3. 完成后，进入「任务与报告 → 报告库」打开该标的的报告。可以对照技术分析、多空论证和最终评级，也可下载 Markdown 或 HTML。

同一工作台一次运行一个任务。关闭浏览器标签页后可重新打开查看进度。退出服务会中断正在执行的任务。

## 4. 查看历史研究

「历史回测」会在选定的标的与采样日期上重复运行研究流程，并按评级汇总结果。若首次试用，选择单一标的和较短日期范围即可控制调用次数。需要续跑时，使用相同的回测编号和参数。「决策记忆」可查看此前的评级及结算后的复盘记录。

## 常见问题

| 现象 | 如何处理 |
| --- | --- |
| 终端找不到 `tradingagents-web` | 检查当前 Python 是否来自刚创建的虚拟环境。在同一环境运行 `python -m tradingagents.web.server --open`。 |
| 默认端口被其他程序占用 | 加上 `--port 8766` 启动，并在浏览器访问 `http://127.0.0.1:8766`。若已运行一个工作台，直接打开它。 |
| 模型鉴权失败或提示找不到模型 | 核对密钥所属服务商，以及快速、深度两个模型的访问权限，保存后重新提交任务。 |
| 报告缺少数据 | 检查代码、交易日期、数据源可达性和服务限额。任务记录会保留本次执行的错误信息。 |
